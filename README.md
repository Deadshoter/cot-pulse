# COT Pulse

Сайт, который показывает, куда ставят крупные фонды — в лонг или в шорт — по 15 фьючерсным рынкам, по официальному отчёту CFTC Commitments of Traders. К каждому рынку ИИ пишет короткие аргументы.

Сайт работает сам: робот GitHub Actions обновляет данные и публикует страницу на GitHub Pages. Ни ваш компьютер, ни Claude для этого не нужны.

## Что и когда обновляется

| Данные | Источник | Как часто |
|---|---|---|
| Позиции фондов и хеджеров | CFTC, отчёт Legacy Futures Only | Проверка каждые 30 минут; новый отчёт появляется по пятницам ~22:30–23:30 по Киеву |
| Цены | Yahoo Finance | Каждые 30 минут с вечера воскресенья до вечера пятницы |
| Аргументы ИИ | Claude через API Anthropic | Один раз после каждого нового отчёта (15 запросов в неделю) |

Открытая страница сама подтягивает свежие цены каждые 5 минут.

## Запуск (один раз, ~10 минут)

1. **Создайте репозиторий.** На github.com → New repository → имя, например `cot-pulse`, тип **Public** (для публичных репозиториев Actions и Pages бесплатны) → Create. Загрузите в него все файлы этой папки (кнопка «uploading an existing file», перетащите содержимое папки, включая скрытые `.github` и `.nojekyll`).
2. **Включите Pages.** Settings → Pages → Source: **GitHub Actions**.
3. **Добавьте ключ ИИ.** Получите API-ключ на console.anthropic.com (Settings → API keys) и пополните баланс на $5 — этого хватит на годы. В репозитории: Settings → Secrets and variables → Actions → New repository secret → имя `ANTHROPIC_API_KEY`, значение — ключ.
4. **Первый запуск.** Actions → «Update data and deploy» → Run workflow, отметьте `force` → Run. Через 2–3 минуты сайт будет по адресу `https://<ваш-логин>.github.io/cot-pulse/`.

Дальше всё идёт по расписанию.

### Необязательно

- `CFTC_APP_TOKEN` (секрет) — бесплатный токен с publicreporting.cftc.gov, снимает лимиты на запросы к CFTC. Без него тоже работает.
- `AI_MODEL` (Settings → Secrets and variables → Actions → Variables) — другая модель Claude. По умолчанию `claude-sonnet-5-5`.
- Свой домен: Settings → Pages → Custom domain.

## Как устроено

```
index.html               сайт (одна страница, без сборки)
data/cot.json            позиции за ~3 года по всем рынкам
data/prices.json         последние цены и цены на даты отчётов
data/ai.json             аргументы ИИ к последнему отчёту
scripts/update_cot.py    CFTC → cot.json (ничего не делает, если отчёт не новый)
scripts/update_prices.py Yahoo Finance → prices.json
scripts/update_ai.py     Anthropic API → ai.json
scripts/common.py        список рынков, оценки показательности, общие расчёты
.github/workflows/update.yml  расписание и публикация
```

Скрипты используют только стандартную библиотеку Python 3.9+. Локально: `cd scripts && python update_cot.py && python update_prices.py && ANTHROPIC_API_KEY=... python update_ai.py`, затем `python -m http.server` в корне и откройте http://localhost:8000.

Если какой-то источник временно недоступен, на сайте остаются последние успешные данные — сайт не ломается.

## Перед тем как брать деньги с пользователей

- **Цены.** Данные Yahoo Finance нельзя использовать в коммерческом продукте. Для платной версии нужен лицензированный источник (например Polygon, Twelve Data, Databento) — меняется только `update_prices.py`.
- **Данные CFTC** — публичные данные госрегулятора США, их можно использовать свободно.
- **Расписание GitHub.** Запуски по расписанию могут опаздывать на 5–15 минут в часы пик. GitHub отключает расписание в репозиториях без активности 60 дней; здесь робот сам коммитит данные, но если давно ничего не менялось — проверьте вкладку Actions.
- **Юридическое.** Страница и аргументы ИИ — аналитика, а не инвестиционные рекомендации; для платного сервиса это стоит закрепить в условиях использования.
